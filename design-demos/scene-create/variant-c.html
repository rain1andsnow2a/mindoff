方案 C · 新场景搭建（剧本生成）

对话引导式 —— 和喵灵聊着聊着，场景就搭好了

整个流程是一场与喵灵桌宠的连续对话：喵灵用气泡一步步问（「想重演哪段经历呀？」），用户用语音或文字回答； 信息以聊天气泡 + 内嵌小卡片呈现——摘要卡、角色卡都可以点开就改。没有表单页、没有步骤条， 用户始终只觉得「在跟一只认真的猫说话」。等待态是本方案的核心：生成时喵灵不消失、不盖黑屏， 而是进入「为你准备场景」的陪伴状态——它在旁边忙碌着、守着，准备进度以一条条小消息陆续发来， 把 60–90 秒变成一场有回应的陪伴，而不是一个转圈的覆盖层。

进度怎么表达不用百分比和进度条。三个阶段（搭场景 → 定语气 → 排开场）化作「准备消息流」，每 8–12 秒发来一条小气泡：完成的带绿勾，进行中的带呼吸黄点。底部只有一条极细的奶油黄呼吸线暗示整体进度——看得见在推进，又不制造倒计时焦虑。
陪伴怎么表达喵灵全程在场：进入忙碌/守着的精灵动画，身下一圈奶油黄柔光随呼吸明暗；头部状态从「在你身边」变成「正在为你准备」。文案温和而具体（「那天的光也调好了，偏暖一点」），每句都回应用户刚说过的话，不是冷冰冰的「正在生成 2/3」。
允许后台等待明确告诉用户「大概一首歌的时间」，可以先去倒杯水：切出 App 后准备好会收到一条喵灵口吻的提醒。场景就绪后以预告小卡收尾（约 5 分钟 · 随时可离开），由用户自己决定「走进去」还是「再坐一会儿」——主动权始终在人这边。
